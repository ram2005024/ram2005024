## <img src="https://user-images.githubusercontent.com/74038190/216122065-2f028bae-25d6-4a3c-bc9f-175394ed5011.png" width="30"/> `$ cat architecture.txt`

<div align="center">
<img src="https://user-images.githubusercontent.com/74038190/212749171-b84692a8-2b04-4e3b-93ca-ac14705da224.gif" width="400"/>

**🔐 Auth flow I'm building:**
Login → FastAPI
├── Access Token → response body
└── Refresh Token → HttpOnly cookie
↓
Frontend: token in Zustand (memory only, never localStorage)
↓
Axios attaches Bearer token to every request
↓
401 received → response interceptor fires
↓
refreshPromise ← single shared promise
(prevents N concurrent refresh races)
↓
New access token → retry ALL queued requests


**⚡ Next.js + React Query boundary:**

/menu, /product/[id] (SEO critical)
↓
Server Component fetches → initialData passed to client
↓
React Query hydrates — ZERO double fetch
↓
Interactions: filters, pagination, cart, mutations
→ React Query owns it
→ Optimistic updates + background refetch


**🗄️ How I think about every DB problem:**

Business problem → Raw SQL → EXPLAIN ANALYZE
↓
Index strategy → SQLAlchemy → Production at scale
