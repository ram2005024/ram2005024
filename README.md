**📁 Service / Repository Architecture (what I actually follow):**
Request → Router → Dependency Injection
↓
Service Layer (business logic)
↓
Repository Layer (DB queries only)
↓
Async SQLAlchemy + PostgreSQL
↓
Pydantic v2 schemas (in/out/db)


**🔐 Auth flow I'm building:**

Login → FastAPI
├── Access Token → response body (short-lived, 15min)
└── Refresh Token → HttpOnly cookie (long-lived, 7d)
↓
Frontend: Access token in Zustand memory (never localStorage)
↓
Axios attaches Bearer token to every request
↓
401 → response interceptor fires
↓
refreshPromise ← ONE shared promise (solves concurrent races)
↓
New access token → retry ALL queued requests simultaneously


**⚡ Next.js + React Query data boundary:**

/menu, /product/[id] (SEO-critical public routes)
↓
Server Component fetches → initialData passed down
↓
React Query hydrates → ZERO double fetch
↓
Interactions: cart, filters, pagination, mutations
→ React Query owns it → Optimistic updates


**🗄️ Database problem-solving approach:**

Business problem → Raw SQL → EXPLAIN ANALYZE
↓
Index strategy → SQLAlchemy ORM → Prod at scale
